# v0.1.0

Initial Runivo MCP stdio server for Windows, macOS and Linux (amd64/arm64).

- Official MCP SDK with tools, resources, prompts and cancellation.
- Existing CLI profile/keychain authentication, explicit API keys and private token files.
- Workspace-scoped operational reads, deployment diagnostics, usage and billing inspection.
- Optional project/service/deployment/domain/backup controls, with independent execution and secret-setting opt-ins.
- Matching core API request IDs, structured errors, private resource caching, bounded output and credential redaction.
- Protocol and API tests, cross-platform race checks and checksummed release archives with provenance.
